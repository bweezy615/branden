## How the owner uses this script
1. **While playing:** capture the clips in the shopping list below. Open each settings page, scroll it slowly top to bottom (about 2 seconds per line), then change the setting you recommend.
2. **Right after:** read the script into a voice memo. Fill each `{FILL: …}` with what you actually saw. **Skip any setting that doesn't exist in the game**; never describe a setting you didn't see. Pause 2 seconds between `##` sections.
3. Upload clips + `v001-vo.m4a` to `Clips IN`.
